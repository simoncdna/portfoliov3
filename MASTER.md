## Theses

**Visual** — Dark "chrome editorial" interface on deep black (`#050505`). Liquid-metal silver/chrome 3D forms are the hero pieces. Oversized condensed grotesque display type in extreme contrast with mono micro-labels. Diffuse silver glow, borderless sharp-edged components, poster/scrapbook layout language (section numbers, vertical labels, barcode, technical markers).

**Interaction** — Slow, organic transitions (350–900ms, expo-out easing). Chrome forms morph and rotate continuously and react to scroll. Masked scroll reveals, magnetic silver hover on links, custom cursor. No bounce, no elastic — everything is fluid glide.

## Color

Chrome is not a single grey — it's a *gradient from white spec highlight to near-black shadow*. The palette encodes that range.

| Token | Hex | Role |
|---|---|---|
| `--void` | `#050505` | Page background (true near-black) |
| `--ink` | `#0B0B0D` | Raised panels / cards |
| `--ink-2` | `#101013` | Hover panel / inset |
| `--steel` | `#26272C` | Hairlines, borders, dividers |
| `--steel-2` | `#3A3B42` | Stronger borders, disabled |
| `--silver-muted` | `#6E7079` | Muted text, captions (meets 4.5:1 on void) |
| `--silver` | `#A8ABB4` | Secondary text |
| `--silver-bright` | `#D6D8DE` | Primary body text |
| `--chrome` | `#EEF0F4` | Headings, high-emphasis |
| `--spec` | `#FFFFFF` | Spec highlight, emissive glow source |

**Chrome gradient** (for text fills, glows, strokes):
`--grad-chrome: linear-gradient(180deg, #FFFFFF 0%, #C9CCD3 22%, #83868F 50%, #E4E6EB 74%, #4A4C52 100%)`
A hard light-to-dark-to-light ramp = the illusion of a curved reflective surface.

**Glow**: `--glow-silver: 0 0 40px rgba(214,216,222,0.25), 0 0 120px rgba(160,163,172,0.12)`

Semantic (rarely used, kept monochrome-tinted):
`--ok: #B8C0BC` · `--warn: #C6BBA6` · `--err: #C6A6A6`

**Contrast rule:** body text uses `--silver-bright` / `--chrome` on `--void` (≥ 9:1). `--silver-muted` is the *lightest* allowed for meaningful text (4.6:1). Never use `--steel*` for text.

## Typography

| Token | Family | Use |
|---|---|---|
| `--font-display` | **Anton** (400) | Mega poster words, hero, vertical section labels. UPPERCASE, tight tracking. |
| `--font-sans` | **Archivo** (400/500/600/800/900) | UI, nav, project titles, body. |
| `--font-mono` | **Space Mono** (400/700) | Meta labels, numbers, dates, barcode captions, kickers. UPPERCASE + wide tracking. |

**Scale** (fluid, `clamp`):
| Token | clamp | Notes |
|---|---|---|
| `--fs-mega` | `clamp(4rem, 18vw, 20rem)` | Hero display, one-word statements |
| `--fs-h1` | `clamp(2.5rem, 8vw, 7rem)` | Section titles |
| `--fs-h2` | `clamp(1.75rem, 4vw, 3.5rem)` | Project titles |
| `--fs-h3` | `clamp(1.25rem, 2vw, 1.75rem)` | Sub-headings |
| `--fs-body` | `clamp(1rem, 1.1vw, 1.15rem)` | Paragraphs |
| `--fs-small` | `0.8125rem` | Secondary |
| `--fs-label` | `0.6875rem` | Mono kickers/labels (tracking `0.18em`) |

**Rules:** display + mono are always UPPERCASE. Body line-height `1.6`, headings `0.92`. Display tracking `-0.02em`, mono tracking `0.16–0.22em`. Line length ≤ 68ch.

## Radii

`--r-none:0 · --r-xs:2px · --r-sm:4px · --r-pill:999px`
Default is sharp (`0`/`2px`). Pills only for tags/toggles (the "US" chip language).

## Shadows / Elevation

Elevation is expressed by **glow and hairline**, not drop shadows (black-on-black).
| Level | Value |
|---|---|
| `--e0` | none (flat on void) |
| `--e1` | `inset 0 0 0 1px var(--steel)` (hairline card) |
| `--e2` | `inset 0 0 0 1px var(--steel-2), 0 0 30px rgba(0,0,0,0.6)` |
| `--e-glow` | `--glow-silver` (chrome / focus / active) |

## Motion tokens

| Token | Value | Use |
|---|---|---|
| `--dur-fast` | `150ms` | Hover, focus, micro |
| `--dur-med` | `350ms` | UI transitions |
| `--dur-slow` | `700ms` | Reveals, entrances |
| `--dur-reveal` | `900ms` | Hero / masked reveals |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | Enters, reveals (expo-out) |
| `--ease-inout` | `cubic-bezier(0.65, 0, 0.35, 1)` | State moves |
| `--ease-in` | `cubic-bezier(0.7, 0, 0.84, 0)` | Exits |
| `--stagger` | `70ms` | List/word stagger |

**Forbidden:** bounce, elastic, `ease-in` on entrances, animating width/height/top/left, scale-to-0, any UI transition > 500ms (reveals/3D exempt — progress/entrance-driven).

## Base components

- **Button (primary)**: `--chrome` text, `--ink` fill, `--e1` hairline; hover → `--e-glow` + text `--spec`, 150ms. Sharp corners (`--r-sm`).
- **Tag / chip**: mono `--fs-label`, `--silver`, `--r-pill`, `1px --steel` border. The "US"-style pill.
- **Link (magnetic)**: `--silver-bright` → `--spec` on hover, animated underline wipe (left→right, 350ms `--ease-out`), magnetic translate ≤ 6px.
- **Card (work)**: flat on void, `--e1` hairline; hover → `--e-glow` + hairline `--steel-2`. No scale-shift that reflows.
- **Cursor**: custom silver ring, blends `mix-blend-mode: difference`; grows on interactive hover.

## Layout language (poster/scrapbook)

Recurring motifs, all mono/`--silver-muted`:
- Section index numerals: `01` … `04` (display or mono, large).
- Vertical rotated label on the right edge (`writing-mode: vertical-rl`).
- Kicker line above titles: `// SCRAPBOOK 20.01` style mono meta.
- Barcode strip + globe glyph in the footer/margins.
- Thin horizontal rules (`--steel`) separating meta rows.

## A11y guardrails

- `prefers-reduced-motion`: kill distort/rotation/reveals, show static chrome, instant states.
- Focus: visible `--e-glow` ring, never removed.
- All interactive elements: default/hover/focus/active/disabled.
- WebGL is decorative → `aria-hidden`; content readable without it.
- Contrast ≥ 4.5:1 everywhere (palette enforces it).
